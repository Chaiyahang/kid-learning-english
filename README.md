# 儿童英语复习

给 4 岁孩子用的课后英语听读工具。家长粘贴老师发来的课堂总结，孩子逐张点卡片听英文发音。

## 线上地址

https://chaiyahang.github.io/kid-learning-english/

手机浏览器打开后「添加到主屏幕」，图标点开直接进孩子页。

## 本地运行

```bash
pnpm install
pnpm test
pnpm dev
```

访问 `https://127.0.0.1:5173/`。首次会提示自签名证书不受信任，继续访问即可。

## 两个界面

- `/` 家长页：粘贴课堂总结、预览拆词结果、保存复习日；底部「学习设置」可开自动朗读并选 1/2/3 次；空状态可一键「载入示例课」体验完整流程。
- `/play` 孩子页：大卡片听读，单词下方显示音标（内置词表覆盖常见幼儿词汇，词表外的词不显示）和中文；顶栏左侧「家长」按钮回家长页；播放按钮点一下朗读、再点停止；顶部进度条显示还剩多少。开启自动朗读后，切卡自动发音。

背景色是淡蓝色（`#cfe3f7`）。图标是「字母积木 A + 发音气泡」，PNG 由 `scripts/generate-icons.py` 生成（iOS 主屏幕、Android maskable 均已覆盖）。

数据只存在当前浏览器 `localStorage`，第一版没有云同步。换设备或换浏览器需要重新录入。

## 部署

推送到 `main` 会自动跑测试、构建并部署到 GitHub Pages（见 `.github/workflows/pages.yml`）。子路径构建用 `pnpm build:pages`；本地和普通 `pnpm build` 仍按根路径输出。

客户端路由是 history 模式，Pages 没有服务端 rewrite，所以构建时把 `index.html` 复制为 `404.html` 作深链回退：直接打开 `/play` 时 HTTP 状态为 404，但内容就是应用，页面正常渲染。

## 验收

1. `pnpm test` 全绿。
2. 粘贴 Letter X 课堂原文，预览出现 X-ray / six / box 等单词和 `I see an X-ray.` 等句子，且不出现歌名或 `Xx～Zz` 这类内容。
3. 粘贴斜杠分隔的单词表（如水果冰沙课），每个词单独成条。
4. 保存后进入孩子页，点 ▶ 能听到英文（Safari / Chrome；微信内置浏览器可能无 TTS）。
5. 「下一个」从最后一张回到第一张；刷新后停在同一张。
6. 无数据时打开 `/play` 回到家长页并提示先录入。
7. 孩子页没有输入框和删除按钮。
