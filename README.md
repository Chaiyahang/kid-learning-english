# 儿童英语复习

给 4 岁孩子用的课后英语听读工具。家长粘贴老师发来的课堂总结，孩子逐张点卡片听英文发音。

## 本地运行

```bash
pnpm install
pnpm test
pnpm dev
```

访问 `https://127.0.0.1:5173/`。首次会提示自签名证书不受信任，继续访问即可。

## 两个界面

- `/` 家长页：粘贴课堂总结、预览拆词结果、保存复习日。
- `/play` 孩子页：大卡片听读，只有发音和上一个/下一个。长按左上角约 1 秒回家长页。

数据只存在当前浏览器 `localStorage`，第一版没有云同步。

## 验收

1. `pnpm test` 全绿。
2. 粘贴 Letter X 课堂原文，预览出现 X-ray / six / box 等单词和 `I see an X-ray.` 等句子，且不出现歌名或 `Xx～Zz` 这类内容。
3. 粘贴斜杠分隔的单词表（如水果冰沙课），每个词单独成条。
4. 保存后进入孩子页，点 ▶ 能听到英文（Safari / Chrome；微信内置浏览器可能无 TTS）。
5. 「下一个」从最后一张回到第一张；刷新后停在同一张。
6. 无数据时打开 `/play` 回到家长页并提示先录入。
7. 孩子页没有输入框和删除按钮。
